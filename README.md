# Kaart-app: Eerste stap bij geldzorgen

Open `index.html` in een browser om de app te gebruiken.

Wat kan de app:
- kaartjes slepen naar de vakken op de placemat;
- kaartjes ook plaatsen door eerst op een kaart en daarna op een vak te klikken;
- maximaal 1 kaart bij vak 1, 2 en 3;
- maximaal 2 kaarten bij vak 4 en 5;
- zinnen onderaan verzamelen;
- opnieuw beginnen met de knop `Opnieuw`;
- printen met de knop `Print`.

Alles werkt lokaal in de browser. Er is geen internetverbinding nodig.

## Online delen via GitHub Pages

Upload de inhoud van deze map naar een GitHub-repository en zet GitHub Pages aan via:

Settings > Pages > Deploy from a branch > main > root

Daarna is de app te openen via:

https://gebruikersnaam.github.io/repositorynaam/
